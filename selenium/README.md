# ZyntraPass — Selenium Web Test Suite

End-to-end Selenium test suite for the ZyntraPass web application.  
**350 unique test cases** covering all pages, buttons, forms, navigation, UI, and performance.

## Folder Structure

```
selenium/
├── config.py               # Central config: URL, credentials, timeouts
├── conftest.py             # Shared fixtures, helpers, login utilities
├── requirements.txt        # Python dependencies
├── generate_report.py      # Generates Excel test report
├── reports/
│   └── selenium_test_report.xlsx
└── tests/
    ├── test_01_landing.py          # TC001–TC020  (Landing/Index page)
    ├── test_02_login.py            # TC021–TC055  (Login page)
    ├── test_03_signup.py           # TC056–TC080  (Organizer Signup)
    ├── test_04_dashboard.py        # TC081–TC115  (Organizer Dashboard)
    ├── test_05_events.py           # TC116–TC150  (Events page)
    ├── test_06_create_event.py     # TC151–TC200  (Create Event 7-step wizard)
    ├── test_07_remaining_pages.py  # TC201–TC280  (Participants, Volunteers, Live,
    │                               #               Certificates, Settings, Attendee,
    │                               #               Multi-tab navigation)
    └── test_08_ui_accessibility.py # TC281–TC350  (UI, Accessibility, Performance)
```

## Setup

```bash
# 1. Install dependencies
pip install -r selenium/requirements.txt

# 2. Update config.py with your Vercel URL and credentials
#    selenium/config.py → BASE_URL, ORGANIZER_EMAIL, etc.

# 3. Generate the Excel report
py selenium/generate_report.py

# 4. Run all tests
cd selenium
pytest tests/ -v --html=reports/selenium_test_report.html --self-contained-html

# 5. Run a specific test file
pytest tests/test_01_landing.py -v

# 6. Run with headless browser (default)
pytest tests/ -v
```

## Configuration

Edit [`config.py`](config.py) to set:

| Setting              | Description                        |
|----------------------|------------------------------------|
| `BASE_URL`           | Your Vercel deployment URL         |
| `ORGANIZER_EMAIL`    | Organizer login email              |
| `ORGANIZER_PASSWORD` | Organizer login password           |
| `ORGANIZER_SECRET_KEY` | Organizer 2FA secret key        |
| `ATTENDEE_EMAIL`     | Attendee login email               |
| `ATTENDEE_PASSWORD`  | Attendee login password            |
| `VOLUNTEER_CODE`     | 4-digit volunteer access code      |
| `HEADLESS`           | Set `False` to watch tests run     |

## Reports

- **Excel**: `selenium/reports/selenium_test_report.xlsx` — color-coded by pass/fail with module summary
- **HTML**: `selenium/reports/selenium_test_report.html` — generated by pytest-html
